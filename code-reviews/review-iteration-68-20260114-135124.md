**BLOCKING ISSUES:**
- **B1: Mailbox `message_id` extraction offset is contradictory** — **RFC-0003 §7.4 (“Message ID Semantics”) vs RFC-0003 §3.2 (PUSE field offsets) and `spec/03-messaging-sync/secure-envelope.md` (PUSE layout)** — RFC-0003 §7.4 states the mailbox MUST extract `message_id` from the stored PUSE envelope “(bytes 41-56)”, but the PUSE header places `message_id` at **offset 46..61** (0-based) (after 4+1+1+20+20 bytes). Two independent mailbox implementers could derive different `message_id` values from the same stored envelope, breaking idempotency and delete/ack behavior.
