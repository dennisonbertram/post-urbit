**BLOCKING ISSUES:**
- B1: Transport connection state naming/semantics diverge (`ConnectionState` includes `'authenticated'` but QUIC lifecycle docs use `'CONNECTED'`/“connected”) — `spec/01-transport-connectivity/interfaces.md` vs `spec/01-transport-connectivity/quic-integration.md` (and echoed in `spec/01-transport-connectivity/overview.md`) — independent implementers can expose incompatible state values/events to higher layers.
- B2: Device Document signature verification key set is inconsistent (verify with identity **current only** vs **current or historical**) — `spec/00-shared/layer-integration.md` (“current (or historical)”) vs `spec/02-identity-trust/identity-document-schema.md` (current only) and `spec/06-rfcs/RFC-0001-identity-document.md` (§12.6 “current signing key”) — leads to incompatible acceptance/rejection of device docs (and therefore divergent device discovery/handshake behavior) after identity signing-key rotation.
