An implementer following §8.2 will fail to verify valid IDOCs (or implement a divergent signature scheme).

This ambiguity blocks interoperable package signing/verification and is security-critical.

Elsewhere (`spec/04-app-runtime/manifest-schema.md:Package Signing` / verification code) the payload uses `HEX(manifest_hash)`. This can cause signatures that don’t verify across implementations.

This mismatch can lead to an incorrect and/or insecure admin auth implementation.
