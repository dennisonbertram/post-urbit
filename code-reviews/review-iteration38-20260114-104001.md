- Evidence:

    - `/** Unix timestamp (ms) when received */ receivedAt: number;`

- Fix:
  - In `spec/01-transport-connectivity/interfaces.md`, remove the duplicate local `interface DhtResult` (and any duplicate `Unsubscribe` if intended to be shared), and import/assume the shared `DhtResult` from `spec/00-shared/layer-integration.md`.

    - `receivedAt: number; // Unix timestamp in milliseconds`
  - Ensure all other references to `DhtResult.receivedAt` are consistent (ms) or update the shared definition and all usages together.
