- File(s): spec/00-shared/test-vectors.md
- Issue: Test Vector 8 is not a concrete, reproducible vector because it omits the derived Ed25519 public key and the resulting DID (expected output). This prevents implementers from validating DID derivation against an authoritative expected value.
- Evidence: 
  - `Device signing public key (derived from seed using Ed25519):`
    `Compute: Ed25519_PublicKey(seed)`

- Fix: Replace the “Compute …” placeholder with fully specified values:

- Fix: Make RFC-0003 test vectors either fully concrete or purely referential:
  - Preferred: Replace placeholders with fully computed values (DH outputs, derived keys, ciphertext length, ciphertext, signature) consistent with `spec/00-shared/test-vectors.md`, and ensure all encodings (Base64 vs Base64url, no padding) match global conventions.
