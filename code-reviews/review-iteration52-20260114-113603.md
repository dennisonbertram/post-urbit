B1: `spec/01-transport-connectivity/interfaces.md` — `TRANSPORT_CONSTANTS.RELAY_PACKET_MAX_SIZE` contradicts the transport-wide QUIC `MAX_UDP_PAYLOAD` (1200) and the RFC PURL header size (44 bytes).  
**Problem:** `RELAY_PACKET_MAX_SIZE: 1500` permits larger UDP payloads than the RFC-0002 QUIC `max_udp_payload_size = 1200` and breaks cross-doc “safe payload” assumptions for encapsulated QUIC-in-PURL.  
**Fix (exact):** change:
```ts
RELAY_PACKET_MAX_SIZE: 1500,
```
to:
```ts
// PURL header is 44 bytes (RFC-0002 §7.4); inner QUIC UDP payload is MAX_UDP_PAYLOAD (1200).
RELAY_PACKET_MAX_SIZE: 1244,
```
(= `MAX_UDP_PAYLOAD + 44`).

**Fix (exact):** in `abi.md` “Common Limits” table, replace:
- `| Message size | 64 KB |`
with:
- `| Message size | 1 MB |`
and (to keep constants unambiguous) add the numeric value:
- `| Message size | 1 MB (1048576 bytes) |`
